# 峡谷漫游记 🗡️🏔️

> 结合王者荣耀角色与成都景点的文化旅游 SPA

一款融合王者荣耀英雄角色与成都历史文化景点的互动式旅游体验应用，让玩家跟着荆轲、李白、诸葛亮等英雄探索武侯祠、杜甫草堂、宽窄巷子……

## 功能特色

- 🗺️ **景点地图** — 互动式成都景点探索
- 👤 **英雄角色** — 王者荣耀角色与历史文化绑定
- 🏆 **成就系统** — 打卡解锁成就徽章 + 全屏庆祝动画
- 📖 **故事模式** — 分支叙事，多种结局
- 🎴 **角色收集** — 收集卡片，解锁故事线
- 💬 **AI 导游** — 虚拟角色互动问答

## 技术栈

- 纯 HTML5 / CSS3 / Vanilla JS（无框架，零依赖）
- 骨架屏加载动画（Skeleton Screens）
- CSS 自定义属性 + 粒子动效

